# Adobe Targetのハイブリッド導入

Adobe Targetでは、クライアントサイドとサーバーサイドの両方でパーソナライゼーションを活用できる、独自のハイブリッドデプロイメントモデルを提供しています。 このハイブリッドモデルでは、技術的な知識がなくても、WYSIWYG Visual Experience Composerを使用して実験アクティビティやパーソナライゼーションアクティビティをオーサリングし、エクスペリエンスをサーバーサイドで実行、配信、レンダリングして、高いパフォーマンスを実現できます。

## 目標

このビデオの終わりまでに、次のことをおこないます。

* Adobe Targetのハイブリッド展開の意味を理解する
* ハイブリッド実装の利点
* ハイブリッド展開によって可能になったサーバーコールの削減を確認します
