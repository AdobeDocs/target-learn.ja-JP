# A/B テストとエクスペリエンスのターゲティング活動でのレコメンデーションオファーの使用

レコメンデーションオファーは、A/B テストとエクスペリエンスのターゲティングアクティビティで使用できます。 この機能により、豊富な機能が開き、次のことが可能になります。

* レコメンデーションと非レコメンデーションのコンテンツを同じアクティビティ内で混在させる
* 複数のレコメンデーションの順序など、ページ上のレコメンデーションの配置を簡単に試すことができます
* 自動配分を使用して、最もパフォーマンスの高いレコメンデーションエクスペリエンスにトラフィックを自動的にプッシュします
* 自動ターゲットを使用して、プロファイルにもとづいてカスタマイズされたレコメンデーション体験に訪問者を動的に割り当て
